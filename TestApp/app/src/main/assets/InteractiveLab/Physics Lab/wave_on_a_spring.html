Core Formulas — Waves on a String

  • Wave equation: y(x,t) = A·sin(kx − ωt + φ)
  • Wave speed: v = f·λ = λ/T
  • Angular frequency: ω = 2π·f = 2π/T
  • Wave number: k = 2π/λ
  • Period: T = 1/f
  • String wave speed: v = √(T_ension / μ) where μ = m/L is linear mass density
  • Standing waves (fixed ends): λ_n = 2L/n, f_n = n·v/(2L)
  • Fundamental frequency: f₁ = v/(2L)
  • Wave energy ∝ A² (intensity scales with amplitude squared)

💡 Quick tips: Doubling frequency halves wavelength (since v is fixed). For a standing wave, each harmonic has a whole number of half-wavelengths fitting between the fixed ends.
