📐 Core formulas
Long straight wire: B = μ₀I/(2πr), μ₀ = 4π×10⁻⁷ T·m/A, so B(µT) = 20·I(A)/r(cm)
Direction: right-hand rule, thumb along I, fingers curl along B (• out of page gives counter-clockwise)
Ampère's law: ∮B·dl = μ₀I_enclosed · Inside a wire of radius a: B = μ₀Ir/(2πa²)
Superposition: B = B₁ + B₂ (vector sum) · Force per length: F/L = μ₀I₁I₂/(2πd) (same direction attract)
Compass: tan(deflection) = B_wire / B_Earth when perpendicular.
Real values: Earth's field is roughly 25–65 µT; horizontal part about 30–40 µT near Ethiopia. Model limits: infinitely long wires, DC currents, no iron.
