Core Formulas — Spherical Mirrors

  • Mirror equation: 1/f = 1/d₀ + 1/dᵢ
  • Magnification: m = −dᵢ/d₀ = hᵢ/h₀
  • Radius relation: R = 2f
  • Sign convention: concave f > 0, convex f < 0
  • Real image: dᵢ > 0 (in front of mirror)
  • Virtual image: dᵢ < 0 (behind mirror)

💡 Key insights: A concave mirror converges parallel light rays toward its focal point F, halfway between the mirror surface and center of curvature C. A convex mirror diverges rays. Three principal rays define the image: (1) Parallel to axis → reflects through F, (2) Through F → reflects parallel, (3) Through C → reflects back on itself. The image is real and inverted if the object is beyond F; virtual and upright if the object is inside F.
