Experiments
Drag the scene to rotate. B points along +z (out of the xy plane).
Physics used
  • F = q(E + v×B)
  • r = γm v⊥ / (|q|B)
  • T = 2πγm / (|q|B)
  • pitch = v∥ T
  • v_drift = E×B / B²
Magnetic force does no work, so speed is constant when E = 0. Integration uses the relativistic Boris scheme, which conserves energy in a pure B field. Limits: point particle, uniform static fields, no radiation loss, no collisions.
