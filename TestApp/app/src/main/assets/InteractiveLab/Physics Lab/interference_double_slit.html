Core Formulas — Double Slit

  • Path difference: Δ = d·sin(θ)
  • Constructive interference: Δ = m·λ (m = 0, ±1, ±2, …)
  • Destructive interference: Δ = (m + ½)·λ
  • Fringe spacing (small angle): Δy = λL / d
  • Fringe position: yₘ = m·λL / d
  • Angular position: sin(θₘ) = m·λ / d

Key insight: Bright fringes occur where the path difference is a whole number of wavelengths. The central fringe (m = 0) is always bright. Fringe spacing increases with longer wavelength or screen distance, and decreases with larger slit separation.
