Section 1.1

Scalars and Vectors

Every measurement in physics is a physical quantity. Some are fully described by a number and a unit — these are scalars. Others need a direction too — these are vectors. This single distinction decides how we add, subtract, and resolve quantities throughout the entire unit.

በፊዚክስ ውስጥ እያንዳንዱ መለኪያ የፊዚክስ መጠን ነው። አንዳንድ መጠኖች በቁጥርና በአሃድ ብቻ ይገለጻሉ — እነዚህ ስካላር ይባላሉ። ሌሎች ደግሞ አቅጣጫም ይፈልጋሉ — እነዚህ ቬክተር ይባላሉ።

The decisive difference:
Scalar = magnitude only → length, mass, time, distance, speed, temperature, volume, density, energy, power.
Vector = magnitude + direction → displacement, velocity, acceleration, force, weight, momentum, impulse, electric field strength.

The critical pair: Distance (scalar) is the total path length. Displacement (vector) is the straight-line change from start to finish with direction.
Speed = distance ÷ time (scalar). Average velocity = displacement ÷ time (vector). ወሳኝ ጥንድ፦ ርቀት (ስካላር) = አጠቃላይ የመንገድ ርዝመት። መፈናቀል (ቬክተር) = ከመነሻ እስከ መድረሻ ቀጥተኛ ለውጥና አቅጣጫ።

Warning: A scalar can be negative (e.g., −3 °C). The minus sign is NOT a direction — it only shows position on a scale.

ማስጠንቀቂያ፦ ስካላር አሉታዊ ሊሆን ይችላል (ለምሳሌ −3 °C)። ሲኒ ምልክቱ አቅጣጫ አይደለም — በመለኪያ ሚዛን ላይ ያለውን ቦታ ብቻ ያሳያል።

Formulas

Speed (scalar): v = d / t   [m/s]
Average velocity (vector): v = s / t   [m/s + direction]

Diagram: Distance vs Displacement

Worked Examples

Example 1.1.1 — Classify six quantities (matric level)

Classify time, force, volume, acceleration, energy, momentum.

  1. Time: Ask "does a complete description need a direction?" Time never does — you can't have "time pointing north". → scalar.
  2. Force: A force must tell you which way it pushes. "20 N" alone is incomplete; "20 N east" is complete. → vector.
  3. Volume: A volume is just an amount of space. A jerrycan holds 20 L regardless of direction. → scalar.
  4. Acceleration: Acceleration has a direction (a car can accelerate north or decelerate). → vector.
  5. Energy: Energy is a quantity (joules) with no direction. → scalar.
  6. Momentum: Momentum = mass × velocity. Since velocity is a vector, momentum inherits its direction. → vector.
Final: Scalars = time, volume, energy. Vectors = force, acceleration, momentum.

Example 1.1.2 — Distance vs displacement (matric level)

A student walks 4 km east, then 3 km north. Find distance and displacement.

  1. Distance: Add the path lengths. 4 + 3 = 7 km. This is a scalar — no direction needed.
  2. Displacement magnitude: The two legs are perpendicular, so the straight-line distance from start to finish is the hypotenuse: √(4² + 3²) = √(16 + 9) = √25 = 5 km.
  3. Displacement direction: The angle from east is tan θ = 3/4 → θ = 36.9° north of east. So displacement = 5 km at 36.9° N of E.
  4. Check: Displacement (5 km) must be ≤ distance (7 km). ✓ It is.
Final: Distance = 7 km (scalar). Displacement = 5 km, 36.9° north of east (vector).

Example 1.1.3 — Average speed vs average velocity (matric level)

A runner completes a 400 m circular lap in 80 s and ends at the start. Average speed and average velocity?

  1. Average speed = total distance ÷ time = 400 ÷ 80 = 5 m/s. This is a scalar — path length used.
  2. Displacement = straight line from start to finish. Start = finish → displacement = 0 m.
  3. Average velocity = displacement ÷ time = 0 ÷ 80 = 0 m/s.
  4. Insight: The runner moved at 5 m/s on average but has zero net velocity over the lap — because velocity depends on displacement, not path.
Final: Average speed = 5 m/s; average velocity = 0 m/s.

Common Mistakes

  • Mass = weight? Mass (kg) is a scalar. Weight (N) is a force — vector, points down.
  • Speed = velocity? Speed has no direction. Velocity needs it: "20 m/s north".
  • Negative temperature has direction? No — scalar sign only marks position on a scale.
  • Displacement > distance? Impossible. Straight line ≤ path length.

Section 1.2

Vector Representations

A vector is written as a bold letter A or with an arrow A⃗. Its magnitude is |A| (always ≥ 0). Graphically, a vector is an arrow: length (to scale) = magnitude, arrowhead = direction. The start is the tail, the tip is the head.

ቬክተር በደማቅ ፊደል A ወይም በቀስት A⃗ ይጻፋል። መጠኑ |A| ነው (ሁልጊዜ ≥ 0)። በስዕል ቬክተር ቀስት ነው፦ ርዝመት (በመለኪያ) = መጠን፣ የቀስቱ ራስ = አቅጣጫ።

Drawing to scale: 1) Choose a scale and write it down. 2) length = magnitude ÷ scale. 3) Draw with ruler and protractor; add the arrowhead. 4) Label the magnitude.

በመለኪያ መሳል፦ 1) መለኪያ ምረጥና ጻፍ። 2) ርዝመት = መጠን ÷ መለኪያ። 3) በገዢና ፕሮትራክተር ሳል፤ 4) መጠኑን ስያሜ ስጥ።

Four types of vectors: Zero (magnitude 0), unit (magnitude 1, only direction), equal (same magnitude AND direction, wherever drawn), negative (−A: same magnitude, opposite direction).

አራት የቬክተር ዓይነቶች፦ ዜሮ (መጠን 0)፣ ዩኒት (መጠን 1)፣ እኩል (መጠንና አቅጣጫ ተመሳሳይ)፣ አሉታዊ (−A፦ መጠን ተመሳሳይ፣ አቅጣጫ ተቃራኒ)።

Formulas

Drawn length = magnitude ÷ scale   [cm]
Magnitude = drawn length × scale

Diagrams

Worked Examples

Example 1.2.1 — Draw a force to scale

Draw 20 N east using scale 1 cm = 5 N.

  1. Identify magnitude and scale: magnitude = 20 N, scale = 5 N per cm.
  2. Apply formula: length = magnitude ÷ scale = 20 ÷ 5 = 4.0 cm.
  3. Draw a horizontal line, mark 4.0 cm with a ruler, add an arrowhead pointing east.
  4. Label it "20 N East". Without the label and scale, the diagram would be meaningless.
Final: Arrow 4.0 cm long pointing east, labelled 20 N East.

Example 1.2.2 — Draw a velocity at an angle

Represent 12 m/s at 60° above the horizontal using 1 cm = 3 m/s.

  1. length = 12 ÷ 3 = 4.0 cm.
  2. Draw a horizontal reference line from the tail point.
  3. Place the protractor at the tail; mark 60° above the horizontal.
  4. Draw the 4.0 cm arrow along that 60° line; add the arrowhead at the tip.
  5. Label "12 m/s at 60° above horizontal".
Final: 4.0 cm arrow at 60° above the horizontal.

Example 1.2.3 — Read a scale diagram

Arrow 5.4 cm on a diagram with 1 cm = 50 km. What displacement does it show?

  1. Formula: magnitude = drawn length × scale.
  2. Substitute: 5.4 cm × 50 km/cm.
  3. Compute: 5.4 × 50 = 270 km.
  4. Direction comes from the arrow's orientation in the diagram (not the length).
Final: 270 km in the direction of the arrow.

Common Mistakes

  • No scale written → arrow length means nothing.
  • No arrowhead → not a vector.
  • |A| = −5 N → impossible; magnitude never negative.
  • "Different position = different vector" → wrong; only magnitude & direction matter.

Section 1.3

Vector Addition and Subtraction

Only vectors of the same kind can be added. Two forces ✓. Two velocities ✓. Force + velocity ✗. Scalar + vector ✗.

የተመሳሳይ ዓይነት ቬክተሮች ብቻ ይደመራሉ። ሁለት ኃይሎች ✓። ሁለት ቬሎሲቲዎች ✓። ኃይል + ቬሎሲቲ ✗።

Not ordinary addition: 3 m east + 4 m north is not 7 m — the result is 5 m (north of east). Direction changes everything.

ተራ መደመር አይደለም፦ 3 ሜ ምስራቅ + 4 ሜ ሰሜን = 7 ሜ አይደለም — ውጤቱ 5 ሜ (ሰሜን-ምስራቅ) ነው።

Resultant R = A + B is the single vector that has the same effect as A and B together. Addition is commutative: A + B = B + A.

ውጤት R = A + B ከ A እና B ጋር ተመሳሳይ ውጤት ያለው አንድ ቬክተር ነው።

Subtraction: A − B = A + (−B). Reverse B to get −B, then add. A − B and B − A have the same size but opposite directions.

መቀነስ፦ A − B = A + (−B)። Bን ቀይረው −B አድርግ፣ ከዚያ ደምር።

Formulas

R = A + B
A − B = A + (−B)
A + B = B + A

Diagram: Subtraction

Worked Examples

Example 1.3.1 — Same direction forces

Two students push east: 40 N and 35 N. Resultant?

  1. Both forces act in the SAME direction (east).
  2. For same direction, magnitudes simply add: R = 40 + 35 = 75 N.
  3. Direction follows the common direction: east.
Final: 75 N east.

Example 1.3.2 — Opposite direction forces

40 N east + 35 N west. Resultant?

  1. Choose a sign convention: east = positive. So +40 N, −35 N.
  2. Add: R = (+40) + (−35) = +5 N.
  3. The positive sign means the resultant points east. So R = 5 N east.
  4. Sanity check: the larger force (40 N east) dominates → the resultant points east. ✓
Final: 5 N east.

Example 1.3.3 — A − B vs B − A

A = 10 m/s east, B = 4 m/s east. Find A − B and B − A.

  1. Set east positive: A = +10, B = +4.
  2. A − B = A + (−B) = (+10) + (−4) = +6 m/s → 6 m/s east.
  3. B − A = B + (−A) = (+4) + (−10) = −6 m/s → 6 m/s west.
  4. Note: A − B = 6 m/s east and B − A = 6 m/s west are negatives of each other (same magnitude, opposite direction).
Final: A − B = 6 m/s east; B − A = 6 m/s west.

Example 1.3.4 — Change in velocity (matric exam classic)

A ball moving 6 m/s east hits a wall and returns at 4 m/s west. Find the change in velocity.

  1. Set east positive: v_initial = +6 m/s, v_final = −4 m/s.
  2. Change in velocity Δv = v_final − v_initial = (−4) − (+6).
  3. = −10 m/s. The minus sign means the change is westward.
  4. Interpretation: Δv = 10 m/s west. The ball's velocity changed by 10 m/s toward the west. This is why hitting a wall reverses the velocity — the change is opposite to the initial motion.
Final: Δv = 10 m/s west.

Common Mistakes

  • Adding magnitudes only, ignoring direction.
  • Thinking A − B = B − A (they're negatives of each other).
  • Adding force to velocity.
  • Forgetting to reverse B when subtracting.

Section 1.4

Graphical Methods of Vector Addition

Three graphical techniques turn vector addition into a drawing exercise with ruler and protractor.

ሦስት ስዕላዊ ዘዴዎች የቬክተር መደመርን በገዢና ፕሮትራክተር ወደ ስዕል ሥራ ይለውጣሉ።

  • Triangle (head-to-tail): Place B at the head of A. R goes from tail of A to head of B. Used for 2 vectors.
  • Parallelogram: Tails together. Complete the parallelogram. Diagonal from common tail = R. Used for 2 vectors.
  • Polygon: Chain vectors head-to-tail. R joins first tail to last head. If chain closes → R = 0. Used for ≥3 vectors.

ትሪያንግል፦ Bን በ A ራስ ላይ አስቀምጥ። R ከ A ጅራት እስከ B ራስ።
ፓራሌሎግራም፦ ጅራቶች አንድ ላይ፤ ከጋራ ጅራት ዲያጎናል = R።
ፖሊጎን፦ ራስ-ወደ-ጅራት ሰንሰለት፤ R የመጀመሪያውን ጅራት ከመጨረሻው ራስ ያገናኛል።

Special cases: Same direction → |R| = A + B (maximum). Opposite → |R| = |A − B| (minimum). Perpendicular → |R| = √(A² + B²); θ = tan⁻¹(B/A).

ልዩ ጉዳዮች፦ አንድ አቅጣጫ → |R| = A + B። ተቃራኒ → |R| = |A − B|። ቀጥተኛ → |R| = √(A² + B²)፤ θ = tan⁻¹(B/A)።

Formulas

Same direction: |R| = A + B
Opposite: |R| = |A − B|
Perpendicular: |R| = √(A² + B²)
θ = tan⁻¹(B/A)

Worked Examples

Example 1.4.1 — Triangle method with Pythagoras

A = 3 units east, B = 4 units north. Resultant?

  1. Vectors are perpendicular → use Pythagoras for magnitude: |R| = √(3² + 4²) = √(9+16) = √25 = 5 units.
  2. Direction from the east direction: tan θ = (north component) ÷ (east component) = 4/3.
  3. θ = tan⁻¹(1.333) = 53.1° north of east.
  4. Full answer: R = 5 units at 53.1° north of east.
Final: R = 5 units at 53.1° N of E.

Example 1.4.2 — Three special cases compared

8 N and 5 N — find R in three cases: same direction, opposite, perpendicular.

  1. Same direction: |R| = A + B = 8 + 5 = 13 N, direction of both forces.
  2. Opposite: |R| = |8 − 5| = 3 N, direction of the larger (8 N) force.
  3. Perpendicular: |R| = √(8² + 5²) = √(64+25) = √89 = 9.4 N. Direction: tan θ = 5/8 → θ = 32° from the 8 N force.
  4. Sanity check: 3 ≤ 9.4 ≤ 13 ✓ — the perpendicular resultant lies between the min and max as expected.
Final: same = 13 N; opposite = 3 N; perpendicular = 9.4 N.

Example 1.4.3 — Polygon method with x-y components

Walk 60 m east, 20 m north, 30 m west, 20 m south. Resultant?

  1. East-west components: +60 (east) − 30 (west) = +30 m east.
  2. North-south components: +20 (north) − 20 (south) = 0 m.
  3. The chain's net displacement is 30 m east with no north-south component.
  4. |R| = √(30² + 0²) = 30 m east.
Final: R = 30 m east.

Example 1.4.4 — River crossing (perpendicular velocity addition)

Boat 3 m/s across a river, current 2 m/s along the bank. Resultant velocity?

  1. The two velocities are perpendicular (across and along the bank are at 90°).
  2. Magnitude: |R| = √(3² + 2²) = √(9+4) = √13 = 3.6 m/s.
  3. Direction from current direction: tan θ = (across velocity) ÷ (along velocity) = 3/2 = 1.5.
  4. θ = tan⁻¹(1.5) = 56.3° from the bank (downstream side).
Final: 3.6 m/s at 56.3° to the bank (downstream).

Example 1.4.5 — Two equal perpendicular forces (matric challenge)

Two 30 N forces act at right angles. Find the resultant.

  1. Both forces have equal magnitude F = 30 N and are perpendicular.
  2. |R| = √(F² + F²) = √(2F²) = F√2 = 30 × 1.4142 = 42.4 N.
  3. Direction: tan θ = (F) ÷ (F) = 1 → θ = 45°.
  4. The resultant lies exactly midway between the two forces.
Final: |R| = 42.4 N, midway between the two forces (45° from each).

Common Mistakes

  • Using Pythagoras for non-perpendicular vectors — only works at 90°.
  • Joining head-to-head or tail-to-tail in the triangle method.
  • Rotating a vector when moving it — only parallel translation allowed.
  • Giving a resultant without direction — always state both.

Section 1.5

Vector Resolution

Resolution is the opposite of combining: one vector is broken into two perpendicular components (usually x and y) that add back up to it.

መከፋፈል የመደመር ተቃራኒ ነው፦ አንድ ቬክተር ወደ ሁለት ቀጥተኛ ክፍሎች ይከፋፈላል።

Trigonometric method: If θ is measured from the +x axis: Aₓ = A cos θ, Aᵧ = A sin θ. Magnitude |A| = √(Aₓ² + Aᵧ²); direction tan θ = Aᵧ/Aₓ. Check the quadrant!

ትሪጎኖሜትሪ፦ θ ከ +x ዘንግ ከተለካ፦ Aₓ = A cos θ፣ Aᵧ = A sin θ። ኳድራንትን ተጠንቀቅ!

Angle from vertical: sine and cosine swap: horizontal = A sin θ, vertical = A cos θ.

ከቁመት አቅጣጫ የሚለካ አንግል፦ ሳይንና ኮሳይን ይለዋወጣሉ፦ አግድም = A sin θ፣ ቁመት = A cos θ።

Resultant by components: Rₓ = ΣAₓ, Rᵧ = ΣAᵧ; |R| = √(Rₓ² + Rᵧ²); θ = tan⁻¹(Rᵧ/Rₓ). Signs decide the quadrant.

በክፍል ዘዴ ውጤት፦ Rₓ = ΣAₓ፣ Rᵧ = ΣAᵧ፤ |R| = √(Rₓ²+Rᵧ²)፤ θ = tan⁻¹(Rᵧ/Rₓ)።

Formulas

Aₓ = A cos θ   (θ from +x)
Aᵧ = A sin θ
|A| = √(Aₓ² + Aᵧ²)
θ = tan⁻¹(Aᵧ/Aₓ)   (check quadrant)
Rₓ = ΣAₓ,   Rᵧ = ΣAᵧ

Diagram: Resolution

Worked Examples

Example 1.5.1 — Resolve a force (from +x axis)

Resolve 50 N at 37° above horizontal.

  1. Identify θ from +x: θ = 37°. Adjacent side = x-component, opposite side = y-component.
  2. Aₓ = A cos θ = 50 × cos 37° = 50 × 0.7986 = 39.9 N.
  3. Aᵧ = A sin θ = 50 × sin 37° = 50 × 0.6018 = 30.1 N.
  4. Check: √(39.9² + 30.1²) ≈ √(1592 + 906) = √2498 ≈ 50 ✓
Final: Aₓ = 39.9 N, Aᵧ = 30.1 N.

Example 1.5.2 — Resolve when angle is from VERTICAL

20 N at 30° from the vertical. Horizontal and vertical components?

  1. The angle is at the TOP (from vertical). The adjacent side is now the vertical component.
  2. Horizontal (opposite side) = A sin θ = 20 × sin 30° = 20 × 0.5 = 10.0 N.
  3. Vertical (adjacent side) = A cos θ = 20 × cos 30° = 20 × 0.866 = 17.3 N.
  4. Check: √(10² + 17.3²) ≈ √(100 + 299) = √399 ≈ 20 ✓
Final: Horizontal = 10.0 N; vertical = 17.3 N.

Example 1.5.3 — Magnitude and direction from components

Aₓ = 12, Aᵧ = 5. Magnitude and direction?

  1. Magnitude: |A| = √(Aₓ² + Aᵧ²) = √(144 + 25) = √169 = 13.
  2. Direction: both components positive → quadrant I, no adjustment needed.
  3. θ = tan⁻¹(Aᵧ / Aₓ) = tan⁻¹(5/12) = tan⁻¹(0.4167) = 22.6° above the +x axis.
Final: |A| = 13 at 22.6° above +x.

Example 1.5.4 — Component method for two vectors (matric level)

A = 10 m at 0°, B = 10 m at 60°. Find the resultant.

  1. Resolve A: Aₓ = 10 cos 0° = 10; Aᵧ = 10 sin 0° = 0.
  2. Resolve B: Bₓ = 10 cos 60° = 5; Bᵧ = 10 sin 60° = 8.66.
  3. Sum components: Rₓ = 10 + 5 = 15.0 m; Rᵧ = 0 + 8.66 = 8.66 m.
  4. Magnitude: |R| = √(15² + 8.66²) = √(225 + 75) = √300 = 17.3 m.
  5. Direction: θ = tan⁻¹(8.66/15) = tan⁻¹(0.577) = 30.0°.
  6. Insight: Because both vectors have equal magnitude, the resultant bisects them (30° is exactly midway between 0° and 60°).
Final: |R| = 17.3 m at 30.0° above +x.

Example 1.5.5 — Quadrant trap (matric classic)

Aₓ = −5, Aᵧ = +5. Magnitude and direction from +x axis?

  1. Magnitude: |A| = √((−5)² + 5²) = √(25 + 25) = √50 = 7.07.
  2. Naive calculator use: tan⁻¹(5/−5) = tan⁻¹(−1) = −45°. This is WRONG as a direction, because it points into quadrant IV.
  3. Check the signs: Aₓ negative (left), Aᵧ positive (up) → quadrant II.
  4. In quadrant II, the angle from +x is 180° − 45° = 135°.
  5. Verify: cos 135° ≈ −0.707, so Aₓ = 7.07 × (−0.707) = −5 ✓; sin 135° ≈ +0.707, so Aᵧ = 7.07 × 0.707 = 5 ✓.
Final: |A| = 7.07 at 135° from +x axis.

Common Mistakes

  • Using cos for vertical when θ is from horizontal — sketch the triangle first.
  • Calculator in radians — always set to degrees.
  • Ignoring component signs — left/down are negative.
  • Trusting tan⁻¹ alone for >90° — check the quadrant and add 180° if needed.
  • Adding magnitudes instead of components — always sum x with x, y with y.
