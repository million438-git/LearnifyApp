Inclined Planes and Machine Efficiency

Unit 5: Simple Machines

Lesson notes

An inclined plane raises an object over a distance rather than lifting it vertically in one movement. In an ideal machine, the smaller force acts over a proportionally longer distance.

Efficiency compares useful output work with input work. Real machines have efficiency below 100% because of friction and other energy transfers. Never assume a machine multiplies energy.

Key relationship

efficiency (%) = useful output work ÷ input work × 100%

Worked example

A machine receives 500 J and provides 350 J useful output. Efficiency = 350 ÷ 500 × 100% = 70%.

Try it yourself

A machine takes in 800 J and delivers 600 J of useful work. Find efficiency.

Reveal suggested answer

600 ÷ 800 × 100% = 75%.
