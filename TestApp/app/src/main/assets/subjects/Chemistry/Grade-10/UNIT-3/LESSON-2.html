Balancing Chemical Equations

Learning objective: Balancing Chemical Equations

Explanation

Equations are balanced by changing coefficients so each element has the same number of atoms on both sides. This reflects conservation of atoms in a chemical reaction.

Key points

  • Do not change chemical formula subscripts.
  • Balance elements systematically.
  • Check all atoms after balancing.
  • Use the smallest whole-number coefficients where possible.

Practical activity

Balance H2 + O2 → H2O, then balance Fe + O2 → Fe2O3.
