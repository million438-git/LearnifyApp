Chemical Reactions and Equations - Unit Exam

Answer each question before revealing the answer. This is supplementary Learnify practice material, not an official examination.

Question 1

In 2Mg + O2 → 2MgO, which substance is a product?

Reveal answer

Magnesium oxide, MgO.

Question 2

Balance: H2 + O2 → H2O.

Reveal answer

2H2 + O2 → 2H2O.

Question 3

What type of reaction breaks one compound into simpler products?

Reveal answer

A decomposition reaction.
