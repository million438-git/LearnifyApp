📘 MASTER SPELLING & PRONUNCIATION RULES
✏️ COMMON SPELLING ERRORS
  • ie / ei : receive (ei after c), believe (ie) — exception: seize, weird
  • -able / -ible : dependable, visible
  • Double letters : beginning, committed, embarrassing
  • Endings -ant / -ent : relevant, confident
  • Common mistakes : accommodate (2 c, 2 m), necessary (1 c, 2 s), separate (‑par‑)
⚡ accommodate (cc, mm) · harass (one r, two s) · embarrass (rr, ss)
🔇 SILENT LETTERS
  • b : debt, doubt, subtle, thumb
  • k / g : knee, knife, gnome, gnat
  • w : write, sword, answer, two
  • h : hour, honest, rhythm, ghost
  • l : half, talk, could, salmon
  • t : castle, listen, whistle, thistle
⚡ psychology (p silent) · island (s silent) · Wednesday (d silent)
🔢 PLURAL FORMS
  • regular : +s / +es (box→boxes)
  • -y : baby→babies (consonant+y) ; day→days (vowel+y)
  • -f / -fe : leaf→leaves, wife→wives (exceptions: roofs, chiefs)
  • -o : potato→potatoes (heroes, echoes) but pianos, photos
  • irregular : child→children, tooth→teeth, mouse→mice
  • same form : sheep, deer, series, species
⚡ crisis→crises · phenomenon→phenomena · cactus→cacti
🇬🇧🇺🇸 BRITISH vs AMERICAN
  • -our / -or : colour (UK) / color (US)
  • -re / -er : centre / center
  • -ise / -ize : organise / organize
  • -ogue / -og : catalogue / catalog
  • -ence / -ense : defence / defense
  • travelling / traveling (double l UK)
⚡ kerb (UK) / curb (US) · tyre / tire · programme / program
