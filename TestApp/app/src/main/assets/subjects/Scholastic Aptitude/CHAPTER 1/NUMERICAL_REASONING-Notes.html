📘 COMPLETE NOTES

🔢 1. number series

  • Arithmetic progression: constant difference (e.g., 5,8,11,14 → +3).
  • Geometric progression: constant ratio (e.g., 4,12,36 → ×3).
  • Mixed / alternating: operations change (e.g., 2,6,7,21,22 → ×3, +1).
  • Special patterns: squares, cubes, primes, Fibonacci.
📌 Example: 3, 6, 12, 24, ? → ×2 → next 48.

⚡ 2. order of operations (BODMAS)

  • Brackets, Orders (powers/roots), Division/Multiplication (left to right), Addition/Subtraction (left to right).
📌 Example: 6 + 4 ÷ 2 × 3 = 6 + (4÷2)×3 = 6+2×3 = 6+6 = 12.

📊 3. fractions, decimals, percentages

  • Fraction = part/whole. 3/5 = 0.6 = 60%.
  • Percentage increase = (new-old)/old ×100%.
  • Common conversions: 1/2=50%, 1/4=25%, 1/8=12.5%.

⚖️ 4. ratios & proportions

  • Ratio a:b means a/b. If two ratios equal, they are in proportion.
  • Dividing a quantity in a given ratio (e.g., 2:3 → parts 2/5 and 3/5).

📈 5. averages (mean, median)

  • Mean = sum of terms / number of terms.
  • Median = middle value when sorted.
  • Weighted average = (w₁x₁ + w₂x₂)/(w₁+w₂).

🚗 6. time, speed, distance

  • Speed = distance / time.
  • Average speed = total distance / total time.
  • Relative speed (opposite directions → add; same direction → subtract).

🏗️ 7. work & rate

  • If a person does work in D days, daily rate = 1/D.
  • Combined rate = sum of individual rates.
  • Time = total work / combined rate.

💰 8. profit, loss & discount

  • Profit = SP - CP ; Profit% = (Profit/CP)×100.
  • Discount = MP - SP ; Discount% = (Discount/MP)×100.

📅 9. simple interest

  • SI = (P × R × T)/100 ; Amount = P + SI.
  • P = principal, R = rate% p.a., T = years.

🔍 10. number properties

  • Prime: numbers with exactly two factors (2,3,5,7,11...).
  • Composite: more than two factors.
  • Squares: 1,4,9,16,... cubes: 1,8,27,64,...
  • Even/odd rules.

🌍 11. real‑world connections

  • Entrance exams, bank tests, job aptitude – all use these skills.
  • Everyday: shopping discounts, splitting bills, fuel efficiency.
