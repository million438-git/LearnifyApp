Key Ideas

A relation pairs elements from one set with elements of another. It can be represented using ordered pairs, a table, a mapping or a graph.

Worked Example

For y = 2x + 1, if x = 3 then y = 2(3) + 1 = 7. The ordered pair is (3, 7).
