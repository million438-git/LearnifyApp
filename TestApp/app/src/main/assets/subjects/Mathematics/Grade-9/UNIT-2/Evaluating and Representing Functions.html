Key Ideas

Substitute an input into a function rule to calculate its output. Tables and graphs help show how outputs change as inputs change.

Worked Example

For y = 2x + 1, if x = 3 then y = 2(3) + 1 = 7. The ordered pair is (3, 7).

Study method: write down the known information, choose the relevant rule, show each calculation, and verify the result.
