Grade 10 Mathematics Formula Reference

  • Rectangle area = length * width.
  • Triangle area = 0.5 * base * height.
  • Rectangular prism volume = length * width * height.
  • Mean = sum of values / number of values.
  • Range = maximum - minimum.
  • Arithmetic sequence nth term = first term + (n - 1) * common difference.
  • Quadratic formula: x = (-b +/- sqrt(b*b - 4*a*c)) / (2*a).
  • Probability = favorable outcomes / total equally likely outcomes.
  • Linear function: y = m*x + c.
