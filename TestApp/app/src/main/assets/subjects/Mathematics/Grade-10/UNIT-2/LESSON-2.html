Understanding Functions

A function assigns exactly one output to each allowed input. For example, f(x) = 2x + 1 is a function.

Example

If f(x) = 2x + 1, then f(3) = 2(3) + 1 = 7.

If an input is assigned two different outputs, the relation is not a function.

Practice

  1. Find f(4) if f(x)=x+6.
  2. Find f(-2) if f(x)=3x.
  3. Can one input in a function have two different outputs?
