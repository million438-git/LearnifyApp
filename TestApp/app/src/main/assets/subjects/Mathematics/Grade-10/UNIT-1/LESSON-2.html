Intervals and Number Line

Intervals describe sets of real numbers. A square bracket means the endpoint is included; a parenthesis means it is excluded.

  • [2,5] means 2 <= x <= 5.
  • (2,5) means 2 < x < 5.
  • [-1,4) means -1 <= x < 4.

On a number line, use a filled dot for an included endpoint and an open dot for an excluded endpoint.

  2. Is 4 included in (1,4)?
  3. Write x > 3 using interval notation.
