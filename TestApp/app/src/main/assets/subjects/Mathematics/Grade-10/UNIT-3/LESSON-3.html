Algebraic Fractions

An algebraic fraction contains an algebraic expression in its numerator or denominator. A denominator must never equal zero.

For example, 6x/3 = 2x. Also, (x^2 + 3x)/x = x + 3 when x is not zero.

Before cancelling factors, factor the numerator and denominator. Never cancel terms that are merely added or subtracted.

Practice

  1. Simplify 8x/4.
  2. Simplify (x^2 + 3x)/x, where x is not zero.
  3. For what value is 1/(x - 2) undefined?
Check answers

1. 2x. 2. x + 3. 3. x = 2.
