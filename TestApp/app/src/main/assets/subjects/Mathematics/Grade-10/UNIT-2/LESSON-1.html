Relations and Ordered Pairs

An ordered pair is written (x,y). A relation is a set of ordered pairs. The domain contains first coordinates and the range contains second coordinates.

For R = {(1,2),(2,4),(3,6)}, the domain is {1,2,3} and range is {2,4,6}.
