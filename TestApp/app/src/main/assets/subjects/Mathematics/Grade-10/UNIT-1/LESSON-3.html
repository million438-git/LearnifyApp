Sets and Set Operations

A set is a collection of distinct elements. The union A union B contains elements in either set. The intersection A intersection B contains elements common to both sets.

Let A = {1,2,3} and B = {3,4,5}. Their union is {1,2,3,4,5}; their intersection is {3}.

The empty set has no elements. The complement of a set contains elements in the universal set that are not in that set.

Practice

  2. Find their intersection.
  3. What does the empty set mean?
