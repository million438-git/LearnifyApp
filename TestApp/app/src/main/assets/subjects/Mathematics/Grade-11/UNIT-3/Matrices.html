🔹 Unit 1 – Relations and Functions

Q1 (2004)
If x < 0, then the simplest form of \( f(x) = \frac{x - |x|}{x} \) is equal to:
  • A) 2x
  • B) 2
  • C) –2
  • D) 0
✅ Correct answer: B) 2
Explanation: For x < 0, absolute value |x| = –x. Then numerator = x – (–x) = 2x. Hence \(\frac{2x}{x} = 2\).

  • A) x – 2
  • B) x + 2
  • C) x
  • D) x
✅ Correct answer: (constant 1) – note that f simplifies to 1, so f(g(x)) = 1 for all x where g(x) ≠ –2. (Options might have misprint; the intended answer is 1, but among given, none match. Possibly D is meant to be 1.)
Explanation: \( f(x) = 1 \) for all x ≠ –2. Therefore \( f(g(x)) = 1 \) for any x such that g(x) ≠ –2. Constant 1.
Q3 (2004)
If \( f(x) = \ln\left( \frac{x}{x-1} + 2 \right) \), for x > 1, then which one of the following is the inverse of f?
  • A) \( g(x) = \frac{e^x - 2}{e^x - 3} \)
  • B) \( g(x) = \frac{e^x - 2}{e^x + 1} \)
  • C) \( g(x) = \frac{e^x}{e^x + 1} - 2 \)
  • D) \( g(x) = \frac{e^x}{x-1} - 2 \)
✅ Correct answer: A
Explanation: Set y = f(x), then \( e^y = \frac{x}{x-1} + 2 \). Solve for x: \( e^y - 2 = \frac{x}{x-1} \) ⇒ \( (e^y - 2)(x-1) = x \) ⇒ expand and isolate x. Finally \( x = \frac{e^y - 2}{e^y - 3} \). Thus inverse is \( f^{-1}(x) = \frac{e^x - 2}{e^x - 3} \).

Q5 (2005)
If \( f(x) = \frac{1}{e^x+1} \), then which of the following is equal to \( f^{-1}(x) \)?
  • A) \( \ln(1-x) - \ln x \)
  • B) \( e^{-x} + 1 \)
  • C) \( \ln\left(\frac{1}{x+1}\right) \)
  • D) \( \frac{1}{e^{-x}+1} \)
✅ Correct answer: A
Explanation: Let y = f(x) = 1/(e^x+1). Then e^x+1 = 1/y ⇒ e^x = 1/y – 1 = (1–y)/y. Taking ln, x = ln((1–y)/y) = ln(1–y) – ln y. So inverse f^{-1}(x) = ln(1–x) – ln x.

Q7 (2006)
If \( f(x) = \sqrt[3]{1 + e^{-x}} \), which of the following is equal to \( f^{-1}(x) \)?
  • A) \( \ln\left( \frac{1}{x^3-1} \right) \)
  • B) \( \frac{1}{\ln(x^3-1)} \)
  • C) \( \ln\left(1 - x^3\right) \)
  • D) \( (1+e^{-x})^3 \)
✅ Correct answer: A
Explanation: Set y = f(x) = (1+e^{-x})^{1/3}. Then y^3 = 1 + e^{-x} ⇒ e^{-x} = y^3 - 1 ⇒ -x = ln(y^3-1) ⇒ x = -ln(y^3-1) = ln(1/(y^3-1)). So f^{-1}(x) = ln(1/(x^3-1)).
Q8 (2007)
The inverse of the function defined by \( g(x) = \frac{2x}{x+3} \) is equal to:
  • A) \( g^{-1}(x) = -\frac{2x}{x-3} \)
  • B) \( g^{-1}(x) = -\frac{x+3}{2x} \)
  • C) \( g^{-1}(x) = -\frac{3x}{x-2} \)
  • D) \( g^{-1}(x) = \frac{x+2}{3x} \)
✅ Correct answer: C
Explanation: Set y = 2x/(x+3). Solve for x: y(x+3) = 2x ⇒ yx + 3y = 2x ⇒ yx – 2x = –3y ⇒ x(y-2) = –3y ⇒ x = –3y/(y-2). Thus inverse = –3x/(x-2).

Q10 (2008)
If the point (3, –2) is on the graph of y = f(x), which point is on the graph of y = f⁻¹(x)?
  • A) (⅓, –2)
  • B) (3, –1)
  • C) (–2, 3)
  • D) (3, –½)
✅ Correct answer: C) (–2, 3)
Explanation: If (a,b) is on f, then (b,a) is on its inverse. So (3,–2) on f ⇒ (–2,3) on f⁻¹.

Q12 (2010)
Let \( f(x) = \frac{3x+1}{x-2} \). Then what is the range of f(x)?
  • A) ℝ \ {2}
  • B) ℝ
  • C) ℝ \ {3}
  • D) ℝ \ {1/3}
✅ Correct answer: C) ℝ \ {3}
Explanation: f(x) = (3x+1)/(x-2). As x → ∞, f → 3. So horizontal asymptote y=3. Also solve y = (3x+1)/(x-2) for x: y(x-2) = 3x+1 ⇒ yx -2y = 3x+1 ⇒ yx-3x = 2y+1 ⇒ x(y-3) = 2y+1 ⇒ x = (2y+1)/(y-3). For y=3, denominator zero, so y=3 not in range. Hence range is all reals except 3.
Q13 (2010)
Which one of the following is true about Signum, absolute value and greatest integer functions?
  • A) sgn(x) = ± |x|, for all x ∈ ℝ
  • B) sgn(x) ≤ x , for all x ≤ 0
  • C) |x| = x sgn(x), for all x ∈ ℝ
  • D) sgn(x) < x , for all x ≥ 0
✅ Correct answer: C
Explanation: By definition, sgn(x) = 1 for x>0, 0 for x=0, –1 for x<0. Then x sgn(x) = |x| for all x (since x·1=x=|x| for x>0, x·0=0=|0|, x·(-1)=-x=|x| for x<0). So C is true.

🔹 Unit 2 – Rational Expressions and Rational Functions

Q1 (2002)
Which of the following is a rational function?
  • A) \( f(x) = \frac{2x^3 - x + \log 2}{x^4 + x^2 + \pi} \)
  • B) \( g(x) = 3x^4 - x^2 + 1 + 2x \)
  • C) \( f(x) = \frac{x^2 - 2x + x}{x^4 + x + 1} \)
  • D) \( \frac{x^2 + \sin x + 2}{x+1} \)
✅ Correct answer: C
Explanation: A rational function is a ratio of two polynomials. A has log, not polynomial. B is polynomial, not ratio. C is ratio of polynomials (x²-2x+x simplifies to x²-x, polynomial). D has sin x, not polynomial. So C is correct.
