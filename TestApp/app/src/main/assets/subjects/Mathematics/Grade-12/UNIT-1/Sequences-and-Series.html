📐 Page 41 – Sigma Notation with Polynomial Terms (Part 1)

We can sum polynomials term‑by‑term using sigma properties.
Example: Σ_{k=1}^{n} (k² + 3k - 2) = Σk² + 3Σk - 2Σ1
Formulas to remember:
Σk = n(n+1)/2    Σk² = n(n+1)(2n+1)/6    Σk³ = [n(n+1)/2]²
Real‑world: Summing areas of rectangles under a curve (Riemann sums) uses these polynomial sums.
Q1: Compute Σ_{k=1}^{10} (k² + 2k).
Step‑by‑step answer:
Σk² = 10×11×21/6 = (10×11×21)/6 = 2310/6 = 385.
Σk = 10×11/2 = 110/2 = 55.
So Σk² + 2Σk = 385 + 2×55 = 385 + 110 = 495.
Concept: Split the sum into known formulas, then add.
Q2: Find Σ_{k=1}^{n} (3k² - k + 4) in terms of n.
Step‑by‑step:
Σ(3k²) = 3·n(n+1)(2n+1)/6 = n(n+1)(2n+1)/2.
Σ(-k) = -n(n+1)/2.
Σ4 = 4n.
Combine: n(n+1)(2n+1)/2 - n(n+1)/2 + 4n = n(n+1)(2n+1-1)/2 + 4n = n(n+1)(2n)/2 + 4n = n²(n+1) + 4n.
Final: n²(n+1) + 4n.
Q3 (Challenge): Prove Σ_{k=1}^{n} (2k-1) = n² using the formulas.
Proof: Σ(2k-1) = 2Σk - Σ1 = 2·[n(n+1)/2] - n = n(n+1) - n = n². Real‑world: Sum of first n odd numbers is a perfect square – e.g., 1+3+5=9=3².

📐 Page 42 – Sigma Notation with Polynomial Terms (Part 2)

Evaluate Σ_{k=1}^{20} (3k - 1) using properties.
Solution: 3Σk - Σ1 = 3×(20×21/2) - 20 = 3×210 - 20 = 630 - 20 = 610.

Q2: Σ_{k=1}^{12} (k² - 3k).
Step‑by‑step: Σk² = 12×13×25/6 = (12×13×25)/6 = 3900/6 = 650.
Σk = 12×13/2 = 78.
Then Σk² - 3Σk = 650 - 3×78 = 650 - 234 = 416.
Q3 (Challenge): If Σ_{k=1}^{n} (ak + b) = 2n² + 3n for all n, find a and b.

This must equal 2n² + 3n. Compare coefficients: a/2 = 2 → a = 4.
Then a/2 + b = 2 + b = 3 → b = 1.

📐 Page 43 – Summation with Variable Indices

When the index starts from a number other than 1, shift the summation.
Example: Σ_{k=3}^{7} (2k-1) = terms: k=3→5, k=4→7, k=5→9, k=6→11, k=7→13, sum=45.
Alternatively: Σ_{k=1}^{7}(2k-1) - Σ_{k=1}^{2}(2k-1) = 49 - (1+3)=45.
Q1: Σ_{k=4}^{8} k².
Step‑by‑step: Σ_{k=1}^{8} k² - Σ_{k=1}^{3} k² = (8×9×17/6) - (3×4×7/6) = (1224/6) - (84/6) = 204 - 14 = 190.
Q2: Σ_{k=2}^{5} (3k+2).
Step‑by‑step: Σ_{k=1}^{5}(3k+2) - (3×1+2) = (3×15 + 2×5) - 5 = (45+10)-5 = 55-5 = 50.
Q3 (Challenge): Σ_{k=m}^{n} 1 = n - m + 1. Prove using index shift.
Let j = k - m + 1, then when k=m, j=1; when k=n, j=n-m+1. Then Σ_{k=m}^{n} 1 = Σ_{j=1}^{n-m+1} 1 = n-m+1.

📐 Page 48 – Infinite Series Convergence Tests (Comparison Test)

If 0 ≤ a_n ≤ b_n and Σb_n converges, then Σa_n converges. If Σb_n diverges and a_n ≥ b_n, then Σa_n diverges.
Example: Σ 1/(n²+1) converges because 1/(n²+1) < 1/n² and Σ1/n² converges.
Q1: Test Σ 1/(n² + n) using comparison.
1/(n²+n) < 1/n², so converges.
Q2: Test Σ 1/√n (p-series with p=1/2) diverges. Compare to harmonic?
1/√n > 1/n for n>1, and Σ 1/n diverges, so diverges.
Q3 (Challenge): Use comparison to show Σ 1/(n!) converges (compare to geometric).
For n≥4, n! ≥ 2^n, so 1/n! ≤ 1/2^n, and Σ 1/2^n converges (geometric, r=1/2).
Page 48 – Comparison test

📐 Page 49 – Ratio Test (Intro)

For Σ a_n, compute L = lim |a_{n+1}/a_n|. If L<1, converges; L>1 diverges; L=1 inconclusive.
Example: Σ 1/n! → a_{n+1}/a_n = 1/(n+1) → L=0 → converges.
Q1: Test Σ 2^n / n!
a_{n+1}/a_n = 2/(n+1) → L=0 → converges.
Q2: Test Σ n/2^n.
(n+1)/2^(n+1) ÷ (n/2^n) = (n+1)/(2n) → 1/2 → converges.
Q3 (Challenge): Find values of x for which Σ x^n converges (geometric, ratio test gives |x|<1).
Ratio test: |x| < 1, so interval (-1,1). At endpoints: x=1 diverges, x=-1 oscillates, diverges.

📐 Page 51 – Applications: Annuities (Geometric Series)

Future value of annuity: FV = PMT × [(1+r)^n - 1]/r.
Example: Save 100 ETB monthly at 0.5% monthly for 2 years (24 months): FV = 100×[(1.005)^24 -1]/0.005 ≈ 2543.20 ETB.
Q1: Deposit 200 ETB monthly at 1% monthly for 1 year.
200×[(1.01)^12 -1]/0.01 = 200×(1.1268-1)/0.01 = 200×12.68 = 2536 ETB.
Q2: Want 10,000 ETB in 5 years at 0.5% monthly, monthly deposit?
PMT = 10000×0.5 / [(1.005)^60 -1] ≈ 5000 / (1.3489-1) ≈ 5000/0.3489 ≈ 143.30 ETB.
Q3 (Challenge): Derive present value of annuity formula using geometric series.
PV = PMT/(1+r) + PMT/(1+r)² + … + PMT/(1+r)^n = PMT × [1 - (1+r)^-n]/r.

📐 Page 52 – Applications: Depreciation (Geometric)

Value after t years = Initial × (1 - depreciation rate)^t.
Example: Car worth 30,000 ETB, depreciates 15% per year. After 6 years: 30,000×(0.85)^6 ≈ 11,310 ETB.
Q1: Machine 50,000 ETB, 20% annual depreciation. After 8 years?
50,000×0.8^8 = 50,000×0.1678 = 8,390 ETB.
Q2: Value after 3 years = 21,000, after 5 years = 15,000. Find initial value and rate.
V₀ r³=21000, V₀ r⁵=15000 → divide: r²=15000/21000=5/7 → r=√(5/7)≈0.845, then V₀=21000/r³≈21000/0.603≈34,825 ETB.
Q3 (Challenge): How long until value drops below 10% of original at 10% depreciation?
0.9^t < 0.1 → t ln0.9 < ln0.1 → t > ln0.1/ln0.9 ≈ (-2.3026)/(-0.10536)≈21.85 years.

📐 Page 54 – Infinite Series: Harmonic and p‑series

Harmonic series Σ 1/n diverges. p‑series Σ 1/n^p converges if p>1, diverges if p≤1.
Q1: Does Σ 1/√n converge?
p=1/2 ≤1 → diverges.
Q2: Σ 1/n^2 converges → sum = π²/6 (known).
Q3 (Challenge): Use integral test to show Σ 1/n diverges.

📐 Page 55 – Alternating Series

Alternating series Σ (-1)^(n-1) a_n converges if a_n decreases to 0.
1 - 1/2 + 1/3 - 1/4 + … converges to ln2.
Q1: Does 1 - 1/√2 + 1/√3 - 1/√4 + … converge?
a_n=1/√n decreases to 0, so converges.
Q2: Estimate error after 10 terms for alternating harmonic series.
Error < a_11 = 1/11 ≈ 0.09.
Q3 (Challenge): Show alternating series test fails if terms do not decrease (e.g., 1 - 1/2 + 1/2 - 1/3 + 1/3 - …).
Terms do not decrease monotonically; the partial sums oscillate but do not converge to a single limit.

📐 Page 56 – Absolute and Conditional Convergence

Σ a_n converges absolutely if Σ |a_n| converges. If Σ a_n converges but Σ |a_n| diverges, it converges conditionally.
Alternating harmonic series converges conditionally.
Q1: Does Σ (-1)^n / n² converge absolutely?
|a_n|=1/n² converges (p=2), so absolutely convergent.
Q2: Σ (-1)^n / √n → converges conditionally (p=1/2 diverges).
Q3 (Challenge): Give an example of a series that converges absolutely but not conditionally (all absolutely convergent are convergent).
Absolutely convergent implies convergent, so every absolutely convergent series is also conditionally convergent? No: conditionally convergent means convergent but not absolutely. Example: Σ (-1)^n/n.

📐 Page 57 – Power Series and Radius of Convergence

A power series Σ c_n (x-a)^n has radius R. Converges for |x-a| Example: Σ x^n / n! converges for all x (R=∞).
Q1: Find radius of convergence for Σ n x^n.
Ratio test: |(n+1)x^{n+1}/(n x^n)| = |x|(n+1)/n → |x| as n→∞. Converges if |x|<1, so R=1.
Q2: For Σ x^n / n, R=1, converges at x=-1 (alternating), diverges at x=1 (harmonic).
Q3 (Challenge): Derive the formula for geometric series as a power series with R=1.
Σ_{n=0}^{∞} x^n = 1/(1-x) for |x|<1, radius R=1.

📐 Page 58 – Applications: Taylor Series (Intro)

Functions can be expressed as infinite power series. Example: e^x = Σ x^n / n! for all x.
Q1: Write sin x as a series.
sin x = x - x³/3! + x⁵/5! - …
Q2: Approximate e^0.5 using first 4 terms.
1 + 0.5 + 0.25/2 + 0.125/6 = 1 + 0.5 + 0.125 + 0.0208333 = 1.64583. Actual e^0.5≈1.64872, error ≈0.0029.
Q3 (Challenge): Use geometric series to find series for 1/(1+x²) and integrate to get arctan x series.
1/(1+x²) = Σ (-1)^n x^{2n}, integrate term by term: arctan x = Σ (-1)^n x^{2n+1}/(2n+1).
